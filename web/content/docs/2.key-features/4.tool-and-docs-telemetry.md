## Summary

Zeeq emits and surfaces extensive telemetry to let teams understand how agents are using the knowledge library and code reviews and where to invest time in having senior engineers manage context.

## Agent document authoring telemetry

The [authoring tools](/docs/key-features/agent-authored-documents) are instrumented like the rest of Zeeq. Every create and update call increments an outcome-tagged counter (`zeeq_create_document_total`, `zeeq_update_document_by_diff_total`) and produces a trace span (`Zeeq.Documents.Create`, `Zeeq.Documents.Edit`). Edit spans record an event for each guard the diff passed through, which makes it easy to see where a rejected diff stopped. When a sync skips a path because a local document owns it, `zeeq_document_sync_skipped_local_total` counts it.

::note
Logs and traces carry operational details only: outcome, library, path, actor, hashes, and rationale length. Document content, diff text, and the rationale text are never logged. The audit record stores snapshots and the rationale separately.
::
